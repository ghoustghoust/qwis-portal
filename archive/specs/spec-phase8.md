# 八期：事件级热点榜 Spec

> 依据：analysis/ai hot/ 参考图 f32bb629（热点榜页）、f8dd5619（事件详情页）、b4cebced（精选页当前热点横条 + 另有 N 家信源标注）。
> 本文档只描述「做什么」，实现留给 plan-phase8.md。

## 背景

七期热榜已对齐 AIHOT 的「条目级」体验（时间轴/评分/双语）。但 AIHOT 还有一层「**事件级**」聚合：同一事件被多家信源报道时聚合成一个「事件」，按热度值排序成榜，并有事件详情页（AI 综述 + 热度走势 + 报道时间线）。

技术事实：AIHOT 无事件级 RSS（feed/hot|events|stories.xml 均 404），事件聚合与热度需**本机计算**；六期日报引擎已有标题相似度去重函数可复用；条目有 score（AIHOT 评分）可作热度权重原料。

## 目标

- 同事件多信源条目自动聚合为事件，按热度排序成榜
- 事件详情：全貌综述 + 热度走势 + 报道时间线
- 精选页与榜单联动（当前热点横条、「另有 N 家信源报道」）

## 功能需求

### F1：事件聚合引擎（本机计算）
- 将近 3 天的 AIHOT 条目按「标题相似度（复用六期 Jaccard 归一化函数）+ 时间窗」聚合为事件簇
- 事件字段：事件标题（取簇内评分最高条目标题）、信源列表、报道数、首发时间、最新时间、簇内条目
- 热度值：Σ(条目评分 × 时间衰减)（24 小时半衰期）；无评分条目按 30 分计；同事件每多一信源有加成；状态标自动推导：6h 内首发=「新」、报道≥5 篇且仍在增长=「爆」、最新报道距今<12h 且首发>12h=「发酵中」
- 聚合结果带缓存（条目变化时失效重建），不锁库

### F2：热点榜视图（/hot/ 内新增「热点榜」）
- 精选 Tab 顶部加「当前热点」横条：前 4 名事件（排名/标题/热度值/迷你走势）+「完整榜单 →」
- 完整榜单：排名列表（01/02…）、事件标题、信源列表（多个换行）、热度值 + sparkline 走势图、状态标（新/爆/发酵中）、榜单底部注释（热度计算公式说明 + 标签含义说明，对齐参考图）
- 点击事件行进事件详情

### F3：事件详情视图
- 页头：「STORY · 事件」标签 + 状态标（进行中/已收尾）、事件大标题、统计行（N 个精选信源 · N 篇报道 · 持续 N 天 · 最新动态时间）
- 「最新进展」卡：最新一篇报道的摘要 + 时间
- 「事件全貌」卡：AI 综述（DeepSeek 对簇内全部条目摘要生成；无 Key 时降级为评分最高条目的摘要 + 标注「AI 未配置，显示最热报道摘要」）
- 「本事件热度走势」：近 24 小时 / 3 天切换的走势图（按簇内条目发布时间 × 评分绘制），显示当前热度/峰值及时间/近 24h 涨跌百分比
- 报道时间线：簇内条目按时间倒序（信源+标题+评分），点击进条目详情（复用七期 HotDetail）

### F4：精选页联动
- 精选/全部动态卡片：同事件条目显示「另有 N 家信源报道」（来自 F1 聚合结果，与日报去重标注同源）
- 当前热点横条点击进对应事件详情

## 非功能需求

- N1: 聚合计算在近 3 天条目（数百条量级）上 <200ms；结果缓存 5 分钟
- N2: AI 综述缓存（事件内容变化或 6h 后才重新生成）；无 DeepSeek Key 时全链路降级可用（N7 原则）
- N3: 走势图用纯 SVG 手绘（不引图表库），三主题兼容
- N4: 事件聚合只作用于 AIHOT 聚合源条目，不动其它源

## 不做的事

- 不做 AIHOT 的「氛围票/评论」体系（我们无此数据）
- 不做事件的持续多天追踪历史页（「持续 N 天」按现有数据计算即可）
- 不把事件聚合引入每日情报页（日报已有自己的去重展示）
- 不抓 AIHOT 的热度值/走势图数据（无公开通道，本机近似计算）

## 验收标准

- AC1（F1）: 已知同事件多报道（如 Cursor 收购 12 家信源）聚合为单一事件，信源数/报道数正确；热度值随时间衰减
- AC2（F2）: 精选页顶部出现当前热点横条（前 4 名）；完整榜单含排名/信源/热度值/sparkline/状态标/底部注释
- AC3（F3）: 事件详情显示统计行/最新进展/事件全貌/热度走势（24h 与 3 天切换数值不同）/报道时间线可点进条目详情
- AC4（F4）: 精选页同事件卡片显示「另有 N 家信源报道」；横条点击进事件详情
- AC5（N1/N2）: 榜单接口响应 <200ms（缓存命中）；无 DeepSeek Key 时事件全貌降级显示且不报错
- AC6（兼容回归）: 七期时间轴/双语详情/收藏、六期日报、阅读器/播放/快照 抽查无劣化；npm test 全绿
