## 2. 用户的页面标注（9 条，按原意登记；每条只附核实到的事实，不附判断）

### /daily/ 每日早报

**① 「每日早报没有精选周刊那样的期号和每日索引」**
核实：期号**有** —— `web/src/components/DailyHeader.jsx:17` 读 `report.issue`，截图上"第 22 期"就是它。缺的是**历史索引端点**：`/api/weekly/archive`、`/api/mybrief/archive` 都存在，**`/api/daily/archive` 不存在**，而库里 `daily_reports` 实有 **47 行**历史。→ 数据在、端点缺。

**② 「每个章节比如：培训课程发布，以及小段文字 课程/训练营/… 这是老版本的布局，不适合当前系统；章节名应该根据今天的内容来决定」**
核实：第 22 期是 `schemaVersion=2`（AI 档），**但五栏仍全部来自 `daily.columns` 关键词表**；AI 生成的 `themes` 只是页面上额外的"主题全景"块。栏目名与 themes 是两套并存的东西。

**③ 「这种要放就放 3 的倍数填满，你只放一个看着很丑陋」**
核实：「培训课程发布」栏本期只有 1 条（该栏关键词：课程/训练营/社群招募/项目培训/技术培训发布或预告）。

**④ 「每日早报的大多数文章只有两颗星或者三颗星的评分也能上到页面来」**
核实（第 22 期 = `daily_reports` id 58，40 条可按 id 回查的文章）：
`5★≥80：2 条(5%)｜4★60-79：12 条(30%)｜3★40-59：20 条(50%)｜2★20-39：6 条(15%)` → **65% ≤3 星，用户观察成立**。
成因：门槛 `DAILY_MIN_SCORE = 30`（`lib/brief-guards.js:54`），而 `Stars = Math.round(score/20)`（`web/src/components/ui/Stars.jsx:8`）→ 30 分就是 2 星。

**⑤ 「视频和播客的标题没翻译」** ＋ **⑥ 「视频和播客没有翻译标题也没有摘要，以及播客的图片和符号有问题，播客可以只放个图片，就像视频一样」**（/mybrief/ 上重复标注，同一件事）
核实：`videos` 表**没有 `translated_title` / `translated_content` 列**（`articles` 有，见 `lib/db.js`）。→ 不是漏跑一次翻译，是**数据层没有承载位**。修它要动表结构 + 三端 SCHEMA 一致 + 翻译管线接线。

**⑦ 「这个功能不明所以，还有高亮功能也是」**（排序下拉：默认排序/最新优先/热度优先）
核实：两个控件**都真的生效** —— `sort` 值传入 `ColumnSection`（`web/src/pages/DailyPage.jsx:260-261,288`），`highlightTitle(title, keywords, enabled)` 按关键词加亮（`ColumnSection.jsx:16,168,245`）。
→ 属**可发现性/无提示**问题，不是死控件。修法是加说明或改交互，不是"接上线"。

**⑧ 「这个是死的吧」**（候选内容 500 卡片）
核实：不是写死的常量，但确实名不副实 —— 值来自 `stats.candidates`，而候选由 `ORDER BY a.published_at DESC LIMIT 500` 得到（**两份实现同句**：`api/daily-generate.js:109`、`tools/collect-turso.js:1137`）。且「候选内容 500」与「公众号文章 500」读的是**同一份 500**（`stats.candidates` 与 `stats.articles` 同为 500），两张卡显示同一个数。

### P0-2 初筛间歇性失效（已讨论完）
