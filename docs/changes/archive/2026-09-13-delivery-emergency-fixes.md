## 1. 本次紧急修复（2026-09-13 凌晨）

### 1.1 云端阅读器点文章白屏（P0 事故）

| 项 | 内容 |
|---|---|
| 现象 | 阅读器点击任何文章 → 整页白屏（React #310） |
| 根因 | 17-translate 引入的手动翻译轮询 `useEffect` 被放在 `if(!articleId)` 早退 return **之后** → hook 数量跨渲染不一致 → 整树崩溃 |
| 修复 | `4b8a71e`：hook 移到所有早退之前 + 注释防再犯；QuickStudyModal 排查无此问题 |
| **事故链教训** | 修复提交后 push 后台任务超时被杀未察觉，导致修复滞留本地 2 小时——**已建立新规则：push 后必须用 `git ls-remote` 确认远端 SHA** |
| 验证 | 本地实测：空态↔选中反复切换 3 轮 + 7 页面遍历，零 React 错误 |

### 1.2 源"批量全挂"报警轰炸（飞书截图）

| 项 | 内容 |
|---|---|
| 现象 | 飞书收到大量「源抓取失败 连续失败 2 次 fetch failed」报警 |
| 真因 ① | **93 个 YouTube 源/轮的反爬假 404**——分类器已识别"反爬可自愈"但仍在逐条发送报警 |
| 真因 ② | **29 个 `127.0.0.1:8001` 本地自建源**（wewerss）被带进 Turso——云端 runner 永远不可达，必然失败 |
| 修复 | `78d1a37`：反爬类 fail<10 不再逐条报警（熔断后走每日汇总）；单轮 >5 源失败聚合为一条分类汇总；runner 与 frozen_digest 均跳过 localhost 源 |
| 效果预期 | 报警量从 ~93 条/2h 降到 ≤1 条汇总/轮 |
