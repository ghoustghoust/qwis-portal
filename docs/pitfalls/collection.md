# 坑 · 采集与信源（collection）

### #4 抓取必须限速超时（2026-08）
- 症状：抓取挂死、整轮采集超时。
- 根因：无头抓取/全文补抓无超时无间隔（微信 3s/篇）。
- 规则：所有外呼 fetch 必须带 `AbortSignal.timeout`；对同一站点串行+间隔。

### #6 调度器串行是有意的
- 症状：改并发后抖音/B站被秒封。
- 根因：平台风控按并发指纹封禁。
- 规则：抖音/B站保持平台级互斥串行；RSS 可并发但每源独立超时。

### #7 熔断机制
- 症状：源"消失"。
- 根因：连失 3 次（YouTube=10）自动 enabled=0，属设计行为非 bug。
- 规则：排障先查 sources.fail_count/enabled；修好后手动启用会清零；反爬类失败勿逐条报警（见 #29）。

### #9 采集语义三份实现漂移（最重量级）
- 症状：修了本地云端不生效，或反向。
- 根因：`server/services/collectors/*`（本地）、`api/collect.js`（Vercel 备份）、`tools/collect-turso.js`（云端主链路）三份独立实现。
- 规则：改过滤/清洗/熔断/去重/UA/钳制任何一处，**必须同步检查另两份**（2026-09-13 pubDate 钳制即三处同步修）。

### #19 newsnow 热榜 API 必须浏览器 UA（2026-09-11）
- 症状：29 个热榜源全 403、19 个被误熔断。
- 根因：自定义 UA（qwis-collector/1.0）被 newsnow 拒绝。
- 规则：UA 统一 Chrome，三处实现各有一份，改要同步。

### #28 大窗口读查询禁止携带 content_html（2026-09-13）
- 症状：weekly 模式启动即 `Fatal: terminated`。
- 根因：7 天窗口 × 2000 行全文一次拉取，libsql HTTP 链路被掐断。
- 规则：大窗口候选查询只取轻列，全文按 id 单取（两步走范式，参考 runTranslate）。

### #29 YouTube 反爬假 404 是常态（2026-09-11 起）
- 症状：YouTube 源每轮 20-80% 概率 404/500，92 源反复熔断。
- 根因：GH runner（GitHub 托管机房 IP）被 YouTube 识别为数据中心 IP 掷骰拒绝——**源是活的，IP 是死的**。与 Vercel 无关（采集不跑在 Vercel）。
- 规则：①熔断阈值 YouTube=10 勿改回 3；②反爬类 fail<10 不逐条报警，熔断后走每日汇总；③根治靠换现成 RSS 源（决策见 docs/specs/22），不要自建爬虫。

### #30 源频率分层（2026-09-13 立项）
- 症状：更新刻度不统一（X 6h、公众号几天一次或一小时腹泻式多篇），源数破千后必然过载。
- 根因：全源共用默认间隔，无分层。
- 规则：新批量导入源按层级写 `extra.intervalMin`（runner 与本地 _shared.js 都认）：Top 级 60min、普通 180min、播客/周刊 360min+；后续演进为自动频率自适应（T4）。
