## 已知规律速记（一分钟版）

1. 密钥三处同步（.env / Vercel env / GH Secrets），改一边=全链路 403 静默停摆。
2. 采集语义三份实现（server/collectors、api/collect.js、tools/collect-turso.js），改一份必查另两份。
3. SQLite 类型序是隐形炸弹：ISO 文本列 vs 数字游标恒真恒假（坑 #25）。
4. 推理模型的输出永远当不可信输入（坑 #24 #26）。
5. 云端回归测试直打生产 Turso，全量替换语义必须快照还原（坑 #27）。
6. 大 payload 慢查询在本地快感觉不出来，云端必炸（坑 #23 #28）。
7. 熔断/反爬类失败是常态，报警要聚合不要轰炸（坑 #29）。
