# ADR-34 · 预筛剔除判据只认形态类，长度/字数类已被行为回测否决

- Status: active
- 拍板：用户 09-24 见到回测读数后裁定「只上形态类，不上长度/字数类」；09-30 确认为现行决策
- 依据：以库内行为正样本（点开过 / 标过稍后读）对每类判据回测，误砍率相差两个数量级；取数口径见 `docs/eval/2026-09-24-prescreen-labels.md` 的行为回测节（读数会漂，要重算就跑那条命令）

【是什么】
预筛层可以用的剔除理由只有**形态类**：内容长得像机器生成的流水（提交记录/更新日志型条目、纯链接清单、导购词表），这些用标题与地址就能判定，不需要理解内容。
**长度类判据（正文多少字、标题几个字、时长多短）不作为剔除理由**——它们已被同一批行为样本否决。

【为什么】
形态类判据在回测里的误砍率接近零：真正的"你点开过的内容"没有一条长得像提交流水。长度类判据正好相反：它砍掉的相当一部分**恰恰是读者真读过的东西**，因为**正文短不等于没营养**——榜单卡片、热榜摘要、产品快讯这类条目天生就短，而它们是这个系统里活跃的一类内容。
这条值得立成决策，是因为"太短的就不要"是所有削减方案里最顺手的第一直觉，每次重新设计都会再想用它一次；而它的否决证据来自真实行为标签，不是推测。

【边界】
- **禁止**用字数、时长、条数、篇幅这类"量出来的长度"作为剔除或降权的理由。长度可以是**取数形状**的考量（不取正文以省载荷），但**不许**是入选与否的判据。
- **新增任何剔除判据必须先过行为标签回测**，并报告它在正样本上的误砍率；没有回测的判据不进这一层。只有形态描述、没有误砍率的主张，视为未验证。
- **禁止**把剔除原因写成"内容质量低"。剔除原因必须是**具体命中的形态**（可回查、可统计），否则削减层会伪装成理解层（ADR-33）。
- 判据必须**双向自证**：坏样本必须被挡、当期真入选内容必须不被挡，防止判据恒真或恒假。
- 本件钉的是"哪些理由合法"，不钉词表内容、阈值数字与规则文件在哪。推翻本件需要**新的行为回测**，不接受"看起来短的就是没营养的"这类直觉论证。
