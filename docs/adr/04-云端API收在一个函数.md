# ADR-04 · 云端 API 收在一个函数里，不拆多函数

- Status: active
- 拍板：用户 09-26 复核确认
- 依据：`api/` 目录结构与 `vercel.json` 重写表实测

【是什么】
全部 `/api/*` 收在同一个 catch-all 函数里，靠一张分发表按路径与方法派发到处理函数。

【为什么】
部署平台的函数数量有配额上限；拆函数等于把业务结构绑在平台配额上，且每加一个端点都要动部署配置。

【边界】
- 加端点是**在分发表里加分支**，不是新建函数文件——那张表因此是必读点。
- **禁止**为"清晰"而把端点拆出 catch-all：那会把配额问题请回来。
- 鉴权门必须挡在分发表**之前**（未带凭据打不存在的端点也应拿到拒绝而不是 404，现状实测如此，有锁钉着）。
