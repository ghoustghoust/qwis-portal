# ADR-21 · runner 依赖面只许纯 JS

- Status: active
- 拍板：用户 09-28 放行（自 `docs/CLOUD_PIPELINE_GUIDE.md` §2 不变量拆出）
- 依据：现读 runner 侧依赖安装口径（不跑编译脚本）；runner 是唯一写入方

【是什么】
跑在 GitHub Actions runner 上的采集与批处理脚本，只依赖**不需编译**的包：托管库客户端、feed 解析、全局 fetch 及其配套。

【为什么】
runner 上安装依赖不跑编译脚本，需要编译的原生模块装不上。而 runner 是这条数据链**唯一的写入方**——依赖装不上不是"少一个功能"，是整条链路起不来，且失败形态是静默无数据而非报错。

【边界】
- **不给 runner 侧脚本加原生模块依赖**（典型是本地库驱动那类）。任何"runner 上装个要编译的包"的提案，先推翻本件。
- 跨端必须同规则的语义一律落 `lib/`，且必须是纯 JS 实现（ADR-14）；本地专属的能力留在本地端，不为了"三端一样"把原生依赖带上 runner。
- 新增依赖前先问：这个包要不要编译脚本？要 → 属本件边界，改本地端或换纯 JS 实现，别试运气。
