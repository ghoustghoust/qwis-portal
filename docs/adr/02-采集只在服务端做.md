# ADR-02 · 采集只在服务端做，需登录态的平台不进云端

- Status: active
- 拍板：用户 09-26 复核确认
- 依据：本地与云端采集实现实测；云端采表面显式排除的类型实测

【是什么】
所有内容获取都发生在服务端进程（runner 或本地进程）。需要登录态才能拿数据的平台——抖音是典型——只在本地采，不进云端。

【为什么】
浏览器侧既带不上服务端节流与 Cookie，也过不了反爬；把这类采集放云端意味着要么塞凭据进函数、要么养一个无头浏览器，两样都和 serverless 的存活时长与冷启动冲突。

【边界】
- **禁止**为任何需登录态的平台设计云端功能；**禁止**为此在云端引入无头浏览器。
- 登录态类平台的功能讨论默认止步于此，不必再评估一次。
- "云端不跑的清单"不作穷举——逐项覆盖以 `docs/FEATURE_MATRIX.md` §1 为准，那里变了本件不动。
- **本件的理由只覆盖"需登录态"这一类**。其他"云端不跑"的东西各有各的原因：长连接推送属 ADR-06，整库文件备份与恢复受托管平台文件系统约束，全文补抓属运行时长时间预算。**不许把它们都归到本件名下**——归错了，下一个人会用错的理由判断"这个能不能上云"。
