# ADR-15 · AI 评分口径：六维固定，生产与评测两名一物

- Status: active
- 拍板：用户 09-11 亲定维度集，09-27 复核确认仍作数
- 依据：提示词实现 + 部署面调用链实测（runner 经读层 AI 模块取该提示词，非本地端专属）

【是什么】
一条内容值不值得进早报，由模型按**六个维度**打分：选题 / 内容 / 深度 / 实用 / 创新 / 表达。各维打分后汇成条目总分。这六个维度是**固定的判断口径**，不是可调参数。

【为什么】
它决定早报的取舍方向。换维度等于换产品判断标准，而不是换一档参数——所以它属决策，不属配置。

这条口径不只影响早报版面。实测的下游有三处都吃同一个总分：**进报质量门槛**、**我的早报探索位的池子准入**、**热点榜的权威加权**。改维度集会同时改这三处的行为，而这三处分散在不同模块里，没人会预期到。这是它必须立在决策件里、而不是留在某段提示词注释里的原因。

【边界】
- **禁止**增删维度、改维度名称或改成任意其它集合，除非先推翻本件。
- **禁止**把本件的六维与**评测侧五维**互抄（评测装置已摘除，其判据口径在 git 历史；重建时见 `docs/EVAL_GUIDE.md` §2）。两者不是一件事：
  - 六维 = **被评对象自己的打分口径**，分值落在条目上、进库、参与上面那三处下游；
  - 五维 = **判卷量具**（LLM-as-a-Judge，另一套分制），只出现在内容质量评测产物里，不参与任何生产决策。
  两份文档原先都只写"维度"二字，抄错会让一次评测读数被当成生产真值读。
- 各维取值范围、门槛数字、权重系数**一律不在本件**——它们是易变参数，读实现；改门槛要走代码（这类键在设置面上没有写入口，界面上改了不生效，别去后台找）。
- 未评分条目**不因缺分而被剔除**（无 AI 分的形态如视频/播客本就无分）。这是一条独立口径，改门槛判据时别把它当漏洞补掉。
- **削减层不许被要求输出绝对分**（与 ADR-33 同一条链的另一半）：让模型给绝对分（分制读实现），是校准漂移的直接来源——抽查实证过"理由写的是关联度低，分数仍给中档"。削减层的**判问**只许问**二元问题**（是不是原创增量 / 是不是纯复述 / 有没有硬伤），绝对分只能来自上面那六个维度的打分任务。（这组"削减层二元判问"与 ADR-27 降级链里的"判断类调用"——评分/摘要/主题归类/导语——**不是同一组**，两个词别互抄。）
  - **禁止**把削减层的输出当分数参与排序或门槛比较；它的契约是"过 / 不过（带原因）"，历史遗留的分数占位值只为护住既有落库形状，**不许**新增取用方。
