# ADR-31 · 精选周刊的构成边界：圈内必看、无破圈、硬上限宁缺毋滥

- Status: active
- 拍板：用户 09-12 定构成口径，09-30 自开发记录中确认为现行决策
- 依据：现读周刊生成流程的候选面与终选步骤（候选排除热榜/聚合形态，终选带条数硬上限与内容不足即少出）

【是什么】
三级内容产品的分工是固定的：每日早报从**全部源**里挑、允许破圈；我的早报只从**订阅集**里挑；**精选周刊只选"本周圈内必看"**——行业大变化、对当前环境有重大影响、成体系的教学、带来新理解的东西。
周刊**不做破圈、不做探索**，条数有硬上限，**不足就少出**，页面显示实际条数。

【为什么】
周刊卖的是"这一周如果只读这些，读这些"——一个**清单承诺**。承诺能成立的前提是它由同一个视角（本周影响力，而不是今日新鲜度）严格筛过。
破圈内容一旦进来，清单立刻退回"又一个推荐流"：探索这件事已经有早报的补充阅读层在做，周刊重复做只会稀释自己的定位。
"宁缺毋滥"是同一件事的另一半：为凑满条数而放宽门槛，产出的不是更厚的周刊，是**第二个日报**——而日报已经存在了。

【边界】
- **禁止**为凑条数降低入选门槛、放宽窗口、或把未通过评分判断的内容补进来。**禁止**在终选之后追加任何补量步骤（包括用热度、随机或"最近读过的同类"补位）。
- **禁止**把破圈/探索位、热榜聚合形态的内容算进周刊。候选面排除它们不是疏漏，是本件。
- **禁止**把周刊做成可配置项（选几条、哪个窗口、什么视角）。它是产品判断，不是参数。
- 条数上限数值、窗口长度、深析预算属易变参数，不在本件写死；补抓机制、降级标记与期号归档见 `docs/features/hot-and-weekly.md` 与 ADR-26。
- **现状：周刊在设置面上零可配项**（没有一期"选几条、改窗口"的格子）。"没做格子"本身不是缺陷，但**也不许把它读成"界面加个格子就行"**——加格子等于把上面那条边界交回用户手改，要先推翻本件。
- 周刊与早报共享同一套评分口径（ADR-15），**视角不同不是分数口径不同**：改分数口径会同时改三级产品。
