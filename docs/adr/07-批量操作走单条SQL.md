# ADR-07 · 批量操作走单条 SQL，不在 serverless 里逐行循环

- Status: active
- 拍板：用户 09-26 复核确认
- 依据：批量端点实现实测（一个带范围参数的端点 + 一条语句）

【是什么】
成组启停、移动、聚焦这类批量动作，是一个带范围参数的端点、一条 SQL 完成，不是"前端循环调用单条接口"。

【为什么】
serverless 里逐行循环必然撞存活时长上限；而且逐行调用会让"一半成功一半失败"成为常态状态，没有可回滚的边界。

【边界】
- **禁止**新增"前端 for 循环打单条接口"的批量实现。
- **禁止**在云端实现里写逐行更新的捷径。批量**语义**两端必须一致——同一批动作对外都走"带范围参数的端点"这个形状；本地实现层虽有逐行的自由，对外暴露的批量行为不得与云端分叉。
