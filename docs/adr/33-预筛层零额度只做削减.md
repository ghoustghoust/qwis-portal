# ADR-33 · 进模型之前的预筛层零额度：这一层的职责是削减，不是理解

- Status: active
- 拍板：用户 09-23/09-24 分两批放行步1 并明确原话「初筛的职责是削减，不是理解」；09-30 确认为现行决策
- 依据：现读候选层的每源限量实现与它在部署面各处的同取；候选池规模与进模型篇数的比值可现读

【是什么】
在内容送进模型之前，有一层**不花任何模型额度的预筛**：它按形态与配额把候选面削小（每个源在候选里最多占几个坑、明显的机器流不进去），削完才轮到模型判断。
这一层的定位是**削减**，不是理解：它只回答"这条值不值得花一次判断"，不回答"这条好不好"。

【为什么】
候选池远大于模型能处理的量，而**池子里的浪费不是随机的**——绝大多数坑位被同一批高频源的后段内容占着。用削减解决这件事，成本几乎为零；用模型解决同一件事，是拿美元去做正则表达式能做的事。
更实际的后果：额度花在削减上，就没额度花在判断上。削减层做不好，模型就变成"给所有东西打一个没人看的分"，而策展质量的瓶颈仍在判断那一侧。

【边界】
- **禁止**在预筛层的任何一级引入模型或 embedding 调用，包括"临时用一次便宜的"。这一层的存在意义就是零额度；一旦引入调用，它就不再是预筛层，而本件覆盖不到那个新层。（向量/检索栈更大范围的禁令见 ADR-20。）
- **禁止**要求这一层输出绝对分数。它只许输出"过 / 不过（带原因）"；"为什么给模型出绝对分这件事本身有害"只论证在 ADR-15 一处，本件不复述。
- **禁止**把削减层的剔除当成质量判断来读。它的产出是"少送进去一些"，不是"这些是好的"；界面与文档都不许把它的剔除写成"评分低"。
- **禁止**拿现成的"领域相关性词表"当入报闸门。词表判的是"像不像本领域"，不是"值不值得读"：用它当闸会把正常源整批准出（已作废规格里那次实测，被判"不相关"的里面包括多家主流媒体与技术站）。要复核这句话，拿这份词表面向近期全量重跑一次判定、看被判不相关的比例。
- **统计臂（词频 / 朴素贝叶斯那一类）只许当兜底排序**：池子超配额时优先牺牲最低分的**最底一小段**。**禁止**把它当"替代 AI 初筛的主力削减层"——它的安全工作点窄到只能砍一成上下，再宽就开始砍掉读者真读过的东西。三个臂之间统计上不可分，所以"选哪个模型"是伪问题，**瓶颈在标签量与标签口径**。读数与口径见 `docs/eval/2026-09-24-prescreen-labels.md` 的三臂行为回测节（数字会漂，要重算就跑 `node tools/eval-prescreen-behavior.cjs`）。
- 这一层里"一个取值被部署面多处取用"（候选池读上限、每源配额）的归属与对账规矩**只写在 ADR-14**，本件不复制取值、也不另定一套口径。
- 具体取值、窗口长度与接入点数量属现场读数，不在本件写死；改削减形状会改变进模型的篇数与覆盖源数，改前先取一次真值。
- 本件与 ADR-24 相互约束：削减是为了换覆盖，**不许**用削掉多样性来换（每源限量换的是什么，见 ADR-09；剔除判据的合法形态见 ADR-34）。
