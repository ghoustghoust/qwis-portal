# ADR-08 · 源的状态拆成互不越权的几轴，不合并回单字段

- Status: active
- 拍板：用户 09-26 复核确认
- 依据：共用实现与生产列实测（四轴各自一列，代码不再依赖旧字段）

【是什么】
一个源的"上架 / 收录 / 订阅 / 重点 / 屏蔽"各占一个字段，互不越权；不再由一个字段兼四职。

【为什么】
单字段复合语义让"下架"和"不再收录"分不开——想只隐藏不删时，改一处动全身，且三端各解释一遍。拆轴后每个动作只写自己那一列。

【边界】
- **禁止**新代码再往旧字段写；旧列只为兼容读而物理保留。
- **禁止**在任何一端另起一套"状态位打包"的写法；四轴只有一份实现（三端共用）。
- 想合并回单字段的提案，先说清楚怎么解决"下架 ≠ 不收录"这一对语义。
- **判定为"解析器缺陷"的失败不参与冻结**：那是我们自己的代码坏了，不是源坏了；锁住源等于把问题藏起来，且解冻后照样坏。这一类只报警、不改变源的状态轴。
