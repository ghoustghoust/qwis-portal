- **关键修复**：GH Secret `COLLECT_KEY` 值错误导致全链路 403 停摆 2 天（数据停在 09-09）；重写三个 Secrets 验证恢复。
- **vercel.json crons 块移除**（GET/POST 不匹配 + 无变量插值，从未生效）。

### 2.2 采集质量修复
- **newsnow 热榜 403**：自定义 UA 被拒 → 全链路浏览器 UA；19 个被误熔断的热榜源复活。
- **YouTube 反爬假 404/500**：数据中心 IP 被间歇封锁（非源死）→ 熔断阈值 3→10，复活 29 个误杀源。
- **RSS 重采间隔 480→60min**：阅读器从"半天不动"变小时级新鲜。
- **dispatch 范围收窄**：cron-job.org 每 15min 的 dispatch 只跑 collect（防日报 15min 刷一份、快照 15min 推一个 commit）。

### 2.3 Agnes AI 修复（重要误诊订正）
- **误诊**："Agnes key 绑 IP"（旧坑 #24）。
- **真根因①**：Turso `settings.ai` 残留 `{apiBase: deepseek域名, model: deepseek-v4-flash}`，settings 覆盖优先级高于 env → 拿 Agnes key 打 DeepSeek 域名 401。
- **真根因②**：agnes-2.5-flash 是**推理模型**，max_tokens=20 被 reasoning 烧光返回空内容。
- **修复**：settings.ai 重置 `{}` + 三处 key 同步（.env/Vercel/GH Secrets）+ max_tokens 64/512 + reasoning_content 兜底。**决策落档：云端 AI 配置锁定 env-only（13 项 F4）**。
