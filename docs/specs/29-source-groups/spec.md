# 源库三视图与组级操作（29-source-groups）

> **状态：草案（未开工）**——总 spec 见 `../26-platform-ia-refactor.md`（四层信息金字塔/源四轴模型）。
> 确认后按 mew-spec 四件套（spec/plan/task/checklist）补全再实施。

## 开发什么

源库默认「组合视图」（组为卡片：源数/正常率/频率/组级操作），「问题源视图」（熔断/报错/新增未确认），检索后才出现现表格；组级批量操作（暂停组/调频/failover 标记）。

## 为什么需要

1446 行表格让操作者面对大海不知所措——以组为单位把日常管理压到几十个卡片。

## 实现目标

日常源管理只看问题源视图（几十个）+ 组卡片一键操作；单源操作进组后可达。

## 验收效果

①默认组合卡片视图 ②问题源视图只列异常 ③组级操作生效于成员 ④检索视图含现全部能力
