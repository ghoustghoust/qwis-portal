## 六、本会话实测踩到的工程坑（接手 Agent 的工作方式提示，Windows + Git Bash）

1. **大段 heredoc（`python - <<'EOF'`）会被截断/转义损坏**——多处 replace 用它翻过车（unterminated string、`\u` 序列被 python 转义成实际字符）。**改文件优先 Read + Edit 工具**；多处同批修改用小段 python 且锚点短而唯一，正则/unicode 内容坚决用 Edit。
2. **管道吃退出码**：`npm run lint:docs | grep …` 的退出码是 grep 的——曾把 1 错带进提交。统一 `set -o pipefail`。
3. **grep 多文件输出会混排**、Read 大文件后凭片段记忆说话会错——关键判断前用 Read 读全段。
4. 锚点匹配警惕**全角/变体字符**（`⚠` vs `⚠️` 差一个变体选择符，replace 会静默失配）。
5. 锁纪律（AGENTS §3）：锁锚点随代码搬家是正当的（意图不变+diff 带为什么），**消红不是**。
