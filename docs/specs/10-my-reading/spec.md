# 我的阅读（沉淀页）Spec

> 来源设计稿：`archive/样图/4.png`（BestBlogs「我的阅读」页）。
> 承接：十期 spec(docs/specs/09）「不做的事」中推迟的本页。本期转入开发计划。

## 背景

用户读过的文章/视频、标记的稍后读与收藏散落在阅读器各 Tab 的隐式状态里（articles.read_at/later、videos.favorite/watched_at)，没有一个统一入口回看"我的阅读沉淀"。设计稿提供了一个按日期分组的聚合页 + 批量管理能力。

现有基础：`GET /api/articles` 支持 tab=history（已读）/later；videos 有 favorite；删除文章没有单条接口（只有按天清理）。

## 目标

- 一个页面回看全部阅读沉淀：读过的、想读的、收藏的。
- 支持批量整理（取消标记/移除记录）与导出。

## 功能需求

- **F1 沉淀聚合页**：读者端新增「我的阅读」页，按日期分组（今天/昨天/更早按日）展示三类内容的并集：已读文章、稍后读文章、收藏视频；每条显示缩略图/占位、标题、来源、类型徽章（文章/播客/视频）、摘要、日期。
- **F2 顶部分段 Tab**：全部 / 已收藏 / 已读 三个分段，各带计数。（设计稿的「有划线」**不做**——系统无划线数据。)
- **F3 类型筛选**：全部 / 文章 / 播客 / 视频 二级筛选（与十期源库的类型判定口径一致）。
- **F4 关键词搜索**：在我的阅读范围内按标题/来源搜索。
- **F5 批量管理**：进入选择模式后可全选/多选，批量执行：取消稍后读、取消收藏、移除已读记录（清 read_at，文章回到未读）。操作有确认与结果反馈。
- **F6 导出**：把选中（或全部）条目导出为 Markdown 清单（标题+来源+日期+链接）下载。

### 待确认决策（推荐项已首选，审批时一并确认）

1. **「已收藏」口径**（推荐 A):A. 文章 later + 视频 favorite 的并集；B. 仅视频 favorite;C. 为 articles 加 favorite 列（违反不加列惯例）。
2. **「移动到文件夹」不做**（推荐）：设计稿的该操作是内容级文件夹，QWIS 文件夹是源级分组，语义不同；本期以 F5 的三个批量动作替代。
3. **「删除」语义**（推荐 A):A. 移除记录=清 read_at（文章回未读，可逆）;B. 真删文章行（不可恢复，影响统计）。

## 非功能需求

- N1 仅本地主系统，不动 portal。
- N2 沉淀量万级时分页/虚拟滚动流畅（复用现有游标分页）。
- N3 批量/移除/导出为受保护写操作；浏览只读公开（与现有鉴权模型一致）。
- N4 视觉遵循 F8 同源约束（t-* 变量、三主题、icons.jsx 风格）。

## 不做的事

- ❌ 划线/高亮功能（无数据基础，属新特性另立项）
- ❌ 内容级文件夹（与源级分组语义冲突）
- ❌ 导出 PDF/EPUB（仅 Markdown)
- ❌ 英文翻译、视频文案提取（沿袭暂缓决策）

## 验收标准

- AC1（F1）：打开「我的阅读」，已读文章/稍后读/收藏视频按日期分组正确显示，与数据库状态一致。
- AC2（F2/F3/F4):Tab 计数准确；类型筛选与搜索组合结果正确。
- AC3（F5）：批量取消稍后读后，这些文章在阅读器稍后读 Tab 消失；批量移除已读后，对应文章回到未读且未读计数回升。
- AC4（F6)：导出的 Markdown 文件内容与选中条目一致，链接可点开。
- AC5(N3)：批量/导出接口无 token 返回 401。
- AC6(N1/N4)：`npm test` 全绿、`npm run build` 通过；三主题下页面显示正常。
