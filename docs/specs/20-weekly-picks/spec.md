# 精选周刊（20-weekly-picks）Spec

## 背景

早报体系第三级（用户已确认）：**精选周刊 = 本周必看的 20 条内容**。定位与两级早报不同：
- 每日早报：全部源挑选（含破圈）
- 我的早报：订阅源专属（无破圈）
- **精选周刊：本周内容挑选，无破圈，只选"圈内必看"**——行业大变化、对当前环境有重大影响、教学课程、新的理解

三级都严格遵循 AI 六维指标（选题/内容/深度/实用/创新/表达）。

需求澄清结论：**无开放问题**——20 条上限、圈内必看、六维判断均已明确。生成时间定为**每周五 18:00（北京，用户 2026-09-12 拍板）**，窗口 = 生成时刻往前 7 天。

## 目标

- 每周一份 20 条的"必看清单"：宁缺毋滥，AI 从一周内容里只选最重要的
- 与早报共用深析思想，但评分视角从"今日价值"变为"本周影响力"

## 功能需求

- **F1**：生成管线（runner `weekly` 模式）：窗口 = 生成时刻前 7 天 → 候选（全源非热榜非聚合器，≤2000）→ 初筛（复用 filterArticle）→ 深析（复用 analyzeArticle 六维）→ **周刊专用终选**：20 条硬上限，按「影响力视角」重排（总分 × 类别加权：行业大变化/重大影响/教学课程/新理解 四类主题识别）→ 导语生成 → 落库 `settings['weekly.latest']`
- **F2**：主题归类：每条入选条目标注主题类别（行业大变化 / 重大影响 / 教学课程 / 新理解 / 其它），前端按类别分组或打标
- **F3**：`GET /api/weekly` 公开读；三态（无数据引导 / 正常 / 生成中）
- **F4**：前端 `/weekly/` 页面：刊头（第 N 期 + 周期日期范围）+ 导语 + 20 条富卡片（排名/类别徽章/评分/理由/摘要/金句/观点/标签）+ 导航入口「精选周刊」
- **F5**：期号与归档：`settings['weekly.archive']` 保留最近 4 期索引（期号/日期/主题），页面可切换查看
- **F6**：降级：AI 失败 → 按热度+六维缓存分的简单排序产出（meta.degraded 标记）

## 非功能需求

- N1：每周一次（周一 00:45 北京），深析预算 ≤150 篇（初筛通过者）
- N2：硬上限 20 条——少而精，不足 20 条时宁缺（显示实际条数）
- N3：与早报共享 `_ai` 通道与降级约束
- N4：归档写入轻量（settings 数组 ≤4 期）

## 不做的事

- 破圈内容（用户明确不要）
- 周刊推送（后续可加，复用 mybrief 推送模式）
- 周刊内的二级栏目（一期就 20 条，不需要）

## 验收标准

- AC1：weekly 模式生成 ≤20 条，每条含六维评分+理由+主题类别
- AC2：无破圈/fallback 来源条目混入
- AC3：周刊页显示刊头（期号+日期范围）+ 导语 + 卡片；归档可切换
- AC4：不足 20 条时显示实际条数不凑数
- AC5：降级时 meta.degraded=true 且仍产出
- AC6：回归测试全绿（配额恢复后真实生成验证）
