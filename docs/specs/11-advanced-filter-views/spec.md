# 阅读器高级筛选 + 保存视图 Spec

> 来源设计稿：`archive/样图/3.png`（筛选展开面板：时间/语言/评分/分类/关键词 + 保存为视图）、`2.png`（智能排序/最新切换、左侧「我的视图」区）。
> 承接：十期 spec(docs/specs/09）「不做的事」中推迟的本块。本期转入开发计划。

## 背景

十期解决了"源"的组织（源库+自动分类）。设计稿 2.png 揭示的另一半问题是 feed 呈现层：全部文章流需要更强的筛选与可复用的视图，让人工筛选出的精华源能被持续高效消费。

现有基础：`GET /api/articles` 已支持 tab/q/日期范围/游标分页/dedup=1 去重；`articles.score` 仅 AIHOT 聚合源有值；无语言字段；无视图存储。

## 目标

- 阅读器文章流提供可组合的高级筛选面板。
- 筛选组合可保存为命名视图，在 Sidebar「我的视图」区一键复用。

## 功能需求

- **F1 排序切换**：文章流支持「最新」（发布时间倒序，现状）与「智能排序」（特别关注源优先 + 时间衰减）两种模式切换，选择记忆。
- **F2 筛选面板**：可展开面板，含以下维度，与现有 tab/分组/来源筛选叠加生效：
  - 时间：全部 / 今天 / 本周 / 本月（映射到现有日期范围参数）
  - 语言：全部 / 中文 / 英文（**判定方式为标题字符集启发式**：含 CJK 字符即中文，否则英文；不落库，查询期计算）
  - 评分：不限 / ≥80 / ≥90（**仅对有评分的条目生效**——即 AIHOT 聚合源条目；无评分条目在选评分档时隐藏并提示）
  - 关键词：复用现有 q 搜索（标题/摘要/正文）
- **F3 保存为视图**：当前筛选组合（排序+时间+语言+评分+关键词+来源/分组范围）可命名保存；Sidebar 新增「我的视图」区列出已存视图，点击即整套应用；视图可删除。
- **F4 视图存储**：视图存 settings（不加表、不加列），上限 20 个，超出提示先删。

### 待确认决策（推荐项已首选，审批时一并确认）

1. **智能排序定义**（推荐 A):A. focus 源优先 + 时间衰减的确定性公式（无 AI，可解释）;B. 仅 focus 源优先、其余按时间；C. 本期不做智能排序，只做筛选面板+视图。
2. **语言筛选**（推荐 A):A. 标题字符集启发式（简单、覆盖绝大多数）;B. 本期不做语言维度。
3. **评分筛选位置**（推荐 A):A. 面板保留但标注「仅热点条目有评分」，文章流中无评分条目按选定档位隐藏;B. 评分筛选只放进热点榜页，文章流不做。

## 非功能需求

- N1 仅本地主系统，不动 portal。
- N2 筛选+视图切换在 600 源/万级文章下响应 <500ms（语言判定走 SQL 预过滤+应用层精判，避免全表内存扫描）。
- N3 视图的写操作受保护；读公开。
- N4 视觉遵循十期 F8 同源约束；筛选面板为三主题适配的浮层。

## 不做的事

- ❌ AI 智能排序/推荐模型（智能排序=确定性公式）
- ❌ 语言字段落库与批量回填
- ❌ 视图分享/同步到云端
- ❌ 英文翻译、视频文案提取（沿袭暂缓决策）
- ❌ 视频流的高级筛选（本期仅文章流；视频已有 favorite/history 分段）

## 验收标准

- AC1（F1)：切换智能排序后，focus 源文章排在非 focus 源之前（同时间窗内）；刷新页面后排序选择保持。
- AC2（F2)：各维度单独与组合筛选结果正确（可对照数据库）；选「评分≥80」时列表只剩有评分且达标的条目，并有范围提示。
- AC3（F3)：保存视图「AI 精选」后出现在 Sidebar 我的视图；点击后筛选面板各维度恢复为保存时的组合；删除后消失。
- AC4（F2 语言）：中文标题条目在「中文」筛选下可见、英文标题条目不可见（启发式边界：中英混合标题按含 CJK 即中文处理）。
- AC5（N3)：视图写接口无 token 返回 401。
- AC6:`npm test` 全绿（含视图存储与智能排序公式的回归测试）、`npm run build` 通过。
