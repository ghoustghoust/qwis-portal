# 后台收敛与对照式管理（30-admin-consolidation）

> **状态：草案（未开工）**——总 spec 见 `../26-platform-ia-refactor.md`（四层信息金字塔/源四轴模型）。
> 确认后按 mew-spec 四件套（spec/plan/task/checklist）补全再实施。

## 开发什么

后台 11→5 Tab：源库/早报中心/热点榜策展/AI能力(含翻译)/系统(数据+监控+报警分区)；对照原则 C1-C3（Tab 顶部前台入口卡/设置项标注作用对象/改动后前台关键数字预览）；IconRail 图标配文字标签；抖音 Tab 下架。

## 为什么需要

后台板块原本多是前台功能的配置面，移到后台后联系断裂——管理者看不出设置影响哪个前台页面；且多数板块只是改几个参数却占独立 Tab。

## 实现目标

后台每个设置项可见其前台作用；前台每个页面可跳到它的策展面；Tab 数 5 个。

## 验收效果

①5 Tab 全功能迁移无丢失 ②每 Tab 有前台对照卡 ③抖音入口移除 ④IconRail 带文字 ⑤移动端可用
