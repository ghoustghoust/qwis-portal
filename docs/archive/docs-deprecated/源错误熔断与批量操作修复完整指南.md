### 1. 后端修复：`refresh-all` 接口增加跳过熔断机制

**文件**: `server/routes/sources.js:114-140`

**修复内容**:
```javascript
// ✅ 修复后：增加 skipBreaker 参数
router.post('/refresh-all', async (req, res) => {
  const skipBreaker = req.query.skipBreaker === '1'; // ← 新增
  
  for (const s of rows) {
    try {
      const r = await fetchSource(s);
      // ... 成功逻辑
    } catch (err) {
      if (skipBreaker) {
        // 仅记录错误但不触发自动暂停
        let extra = {};
        try { extra = JSON.parse(s.extra || '{}'); } catch { /* ignore */ }
        extra.lastError = log.mask(String(err.message || '未知错误')).slice(0, 300);
        extra.lastErrorAt = nowIso();
        db.prepare("UPDATE sources SET extra=? WHERE id=").run(JSON.stringify(extra), s.id);
        results.push({ id: s.id, name: s.name, ok: false, error: err.message, autoPaused: false });
      } else {
        const { failCount, autoPaused } = markSourceError(s, err.message);
        results.push({ id: s.id, name: s.name, ok: false, error: err.message, failCount, autoPaused });
      }
    }
  }
  res.json({ ok: true, total: results.length, succeeded: okCount, failed: results.length - okCount, results });
});
```

### 3. 前端增强：WempTab 显示所有通用订阅源

**修改文件**: `web/src/components/WempTab.jsx:L211-218`

**修复前**:
```javascript
const loadSources = useCallback(async () => {
  const data = await api.get('/api/sources?type=wemp'); // ❌ 只加载 wemp 类型
  setSources(...);
}, []);
```

**修复后**:
```javascript
const loadSources = useCallback(async () => {
  const data = await api.get('/api/sources'); // ✅ 获取所有类型
  const all = Array.isArray(data) ? data : data?.items || data?.sources || [];
  setSources(all.filter((s) => s.type !== 'hotlist')); // ❌ 过滤掉热榜源
}, []);
```

## 🚀 紧急恢复操作流程

### 场景 1: 大量源熔断导致无法刷新

**操作步骤**:

1. **一键解冻**（推荐优先使用前端 UI）:
   - 管理后台 → 公众号订阅 Tab
   - 运维状态面板 → 点击「一键解冻全部 (N)」
   - 或手动输入 SQLite 命令:
   
```sql
UPDATE sources 
SET enabled=1, fail_count=0, status='ok', 
    extra=json_replace(json_extract(extra,'$'), '$.lastError', NULL, '$.lastErrorAt', NULL)
WHERE fail_count >= 3 AND enabled=0;
```

2. **批量刷新**:
   - B 站/抖音 Tab → 点击「批量刷新已启用」
   - 微信公众号 Tab → 点击「全部刷新」（已优化 skipBreaker）

3. **监控未来 1h 日志**:
```powershell
# PowerShell 实时过滤错误日志
Get-Content _phase7-server.log -Wait | Select-String "错误|ERROR" | Select-Object -Last 20
```

---

### 场景 2: B 站持续签名失败

**操作步骤**:

1. **诊断 B 站状态**:
   ```bash
   node tools/ops-toolkit.js diagnose-bili
   ```

2. **重新扫码授权**（如诊断显示 Cookie 未配置）:
   - 管理后台 → B 站 Tab
   - Cookie 配置区 → 粘贴新的 SESSDATA
   - 保存后再次诊断

3. **强制刷新密钥**:
   ```bash
   # 临时删除 B 站相关源的额外缓存（下次抓取会重新获取）
   UPDATE sources SET extra='{}' WHERE type='bilibili';
   ```

---
