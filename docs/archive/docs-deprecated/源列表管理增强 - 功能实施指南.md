# 源列表管理增强 - 功能实施指南

## 一、功能概述

本次更新为管理后台的所有源列表 Tab 页面添加了以下高级功能：

### ✅ 已实现的功能

1. **分页显示机制**
   - 每页默认显示 20 条记录
   - 支持手动切换页数
   - 页脚显示"第 X 页 / 共 Y 页，总计 Z 条"
   - 智能分页控件（当前页前后±2 页 + 首尾页）

2. **高级搜索过滤栏**
   - **模糊搜索**: 同时匹配名称 (name)、URL、错误消息 (extra.lastError)
   - **状态筛选器**:
     - "全部"（默认，显示所有）
     - "刷新异常" (status='error' 或 fail_count ≥ 3)
     - "已熔断" (enabled=0 AND fail_count ≥ 3)
     - "最近失败" (lastErrorAt 在过去 24 小时内)
   - 防抖处理（300ms 延迟触发），避免频繁渲染

3. **可视化状态标识增强**
   - **状态徽章**: 
     - ✅ 正常（绿色 badge-on）
     - ⚠️ 异常（红色 badge-red，tooltip 显示完整错误信息）
     - 🔴 熔断（红色熔断标志，标题提示"连续失败≥3 次"）
     - 🟢 已启用/已停用（根据 enabled 状态变化颜色）
   - **Tooltip 支持**: 悬停显示 lastError 等详细信息
   - **类型标签**: RSS(橙色)/X(黑色)/YouTube(粉色)/B 站 (粉红)/抖音 (深灰)/微信 (绿色)

4. **批量操作能力**
   - 复选框模式（仅在选择时显示）
   - 批量选中所有报错源
   - 批量取消选择
   - 显示当前选中数量

5. **性能优化**
   - 前端本地过滤优先（无需后端介入）
   - React useMemo 缓存过滤结果
   - 搜索输入防抖（300ms）
   - 分页仅渲染当前页数据

## 五、故障排查

### ❌ 问题：搜索框不显示

**可能原因**: 组件未重新编译

**解决方法**:
```powershell
# 检查 web/dist 是否存在最新构建
cd d:\全网情报系统\web
npm run build

# 重启服务
cd ..
.\restart-server.bat
```

### ❌ 问题：分页控件消失

**可能原因**: 数据量小于阈值或分页逻辑错误

**调试步骤**:
1. 浏览器 F12 打开控制台
2. 查看是否有 JavaScript 错误
3. 检查网络请求返回的数据量

### ❌ 问题：熔断源未被识别

**可能原因**: 数据库字段不一致

**验证命令**:
```powershell
node -e "const {db} = require('./server/db'); const frozen = db.prepare('SELECT COUNT(*) c FROM sources WHERE fail_count >= 3 AND enabled=0').get(); console.log('熔断源:', frozen.c);"
```

**预期输出**: 应该显示实际数量（之前是 86 个）

### ❌ 问题：状态徽章颜色不对

**检查点**:
- Tailwind CSS 是否加载成功
- `--green`, `--red` 等 CSS 变量是否定义
- class name 是否正确拼写

## 六、技术实现细节

### 📦 SourceTable 组件参数说明

```jsx
// Required parameters
rows           // Array - 数据行数组
columns        // Array - 列定义数组，每项包含：
               //   key         // String - 数据字段名
               //   title       // String - 表头标题
               //   render?     // Function - 自定义渲染函数

// Optional parameters
pageSize      // Number - 每页显示数量，默认 20
searchPlaceholder // String - 搜索框提示文字
enableFilter  // Boolean - 是否启用筛选器，默认 true
```

### 🎨 状态徽章配色方案

| 状态 | 颜色类 | OKLCH | 使用场景 |
|-----|--------|-------|---------|
| 正常 | `badge-green badge-on` | L 0.66 C 0.12 h 142° | enabled≠0 且无错误 |
| 停用 | `badge-green badge-off` | L 0.62 C 0.08 h 142° | enabled=0 |
| 异常 | `badge-red badge` | L 0.65 C 0.22 h 350° | status='error' |
| 熔断 | `badge-red badge` | L 0.60 C 0.25 h 350° | fail_count≥3 && enabled=0 |

### 🔍 搜索过滤优先级

```javascript
// 1. 搜索关键词过滤 (name/url/lastError)
// 2. 状态筛选器过滤
// 3. 前端本地计算完成，无需后端 API

// 防抖控制
useEffect(() => {
  const timer = setTimeout(() => setSearch(search), 300);
  return () => clearTimeout(timer);
}, [search]);
```

### 📊 分页计算逻辑

```javascript
const totalPages = Math.ceil(total / defaultPageSize) || 1;
const startIndex = (currentPage - 1) * defaultPageSize;
const paginatedRows = filteredRows.slice(startIndex, startIndex + defaultPageSize);
```
