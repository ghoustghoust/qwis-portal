## 为什么文字被清出去

用户 09-25 立的是「作废即删，不养旧文」，可执行细则在 `docs/DOC_GOVERNANCE.md` §2.2：**不静默删除由 git 承担（删除批次的提交信息即台账），不由"文件还在原地"承担**（10-06 起不再另立作废登记表）。
归档层却一直在长大成第二个事实源：它按 §2.3 收"已验收/已完结"的文字，而**验收完的文字里仍然挂着当时的判断与口吻**，下一个动手的人会照它干活。2026-10-01 对归档层做同一把尺子（§2.5 三种去处）逐份过完，结论是：

- 仍生效的取舍与边界，**全部搬进了新家**（`docs/adr/`、`docs/features/`、`docs/pitfalls/`、`docs/RUNBOOK.md`、`docs/ISSUES.md`）；
- 剩下的是流水、一次性读数、以及描述**已被判死方案**（自建公众号引擎、宝塔/PM2/Nginx 部署、扫码登录态那几代）的手册——它们只会被误当现状；
- 于是 85 份文字件（66 `.md` + 18 份一次性运行输出 + 1 份 html 报告）整批删除，反查走 git。

**今后核销出账的文字按同一规矩办：搬完即删，不再搬进本目录。**
