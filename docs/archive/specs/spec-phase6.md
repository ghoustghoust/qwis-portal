# 六期：日报保鲜 + 阅读器日历筛选 + AIHOT 修复 + 热点榜 Spec

> 依据：用户在真实使用中反馈的四组问题（日报时效、无法判断内容时间范围、AIHOT 乱码/滞后/权重、希望有类似 AIHOT 的热点榜）。
> 本文档只描述「做什么」，实现留给 plan-phase6.md。

## 背景

系统一~五期已完成：三页面（/reader/ /daily/ /wechat/）、公众号/B站/抖音/YouTube/通用 RSS/X 六类源、AI 速览、每日情报日报。真实使用中暴露：

1. 日报 cron 到点生成，但若用户当日到点前未打开过页面，会以为「没生成」；且「重新生成」旧版不会先抓新数据（已部分修复）
2. 阅读器列表无法按时间范围筛选，内容跨度从 2003 年（阮一峰博客全量存档）到今天，用户无法判断「看到的覆盖哪段时间」
3. AIHOT 源名称乱码（`AIHOT `）；其日更 60+ 条但我们 8h 才抓一次，既滞后又漏条；日报里 AIHOT 无权重控制会淹没官博
4. 用户希望有类似 AIHOT 官网（精选/全部动态/分类/搜索/中英对照）的「热点榜」页面

## 目标

- 日报数据新鲜：打开即是今日内容，重新生成先补抓
- 阅读器可按日期范围筛选（文章 + 视频）
- AIHOT 修复乱码、提频到 30 分钟、日报限流去重
- 新增第 4 页面 /hot/ 热点榜：AIHOT 为主数据源，分类精选 + 全部动态 + 搜索 + 中文卡片/一键英文原文

## 功能需求

### F1：AIHOT 名称乱码修复
修正数据库中 AIHOT 源名称（`AIHOT `→「AIHOT 热榜」）；排查提交链路确保以后中文名称不再乱码（HTTP 请求体统一 UTF-8）。

### F2：源级刷新频率覆盖
每个订阅源可单独设置刷新间隔（覆盖全局默认），设置页可见可改（分钟/小时输入 + 「恢复默认」）；AIHOT 默认 30 分钟。未单独设置的源维持全局间隔不变。

### F3：日报「打开即补」
打开 /daily/ 时检查：当前时间已过今日「每日生成时间」且今日尚未生成 → 自动触发生成（顶部提示生成中/完成）；「重新生成」按钮保持「先补抓到期源再生成」的既有行为。

### F4：阅读器日期范围筛选
- 中间列表头部（紧挨排序按钮）加日历按钮 📅，点击弹出浮层：快捷段「今天 / 近3天 / 近7天 / 近30天 / 全部」+ 自定义开始日~截止日
- 筛选与已选源/分组/历史搜索/Tab 叠加生效；激活时按钮显示当前范围（如「8/14~8/16」），可一键清除
- 文章 Tab 与视频 Tab 均支持；游标分页在筛选下正常翻页
- 列表头部显示当前内容的实际时间跨度（最早~最新发布日期）

### F5：日报限流与跨源去重
- 同主题去重：不同源报道同一事件（标题/关键词高重叠，如 AIHOT 与官博同时报「Cursor 被收购」）时合并为一张卡片，标注「另有 N 家信源报道」
- 高频源限流：同一栏目内同一来源最多入选 3 条（按规则命中度/时间取前 3），超出不再收录
- 去重合并优先级：官博原文 > AIHOT 译制 > 其它

### F6：热点榜页面 /hot/（第 4 页面）
- 导航栏加入口（与阅读器/日报/设置并列）
- 「精选」Tab：顶部分类胶囊——全部 / 模型 / 产品 / 行业 / 论文 / 教程 / 观点；卡片流展示（标题 + 中文摘要 + 信源 + 相对时间 + AIHOT 分类标签）
- 「全部动态」Tab：时间线列表 + 搜索框（标题/内容）
- 数据源：AIHOT 源的文章（feed 含中文译文、category、author 信源名）
- 分类归类规则：AIHOT category 映射为主（如 模型发布→模型、产品更新→产品、行业动态→行业、论文→论文、教程/实践→教程、大佬观点/现象/趋势→观点），未命中进「全部」可见、分类胶囊下不出现；规则表可在设置中查看

### F7：热榜详情与英文原文
- 点卡片开详情：中文译文完整渲染 + 信源/时间/分类标签
- 「查看英文原文」按钮：抓取原文页（Readability 提取）展示英文全文；加载失败给「阅读原文 ↗」跳转兜底
- 「复制链接」「打开原文」按钮齐全

### F8：热榜设置可见性
设置页新增「热点榜」区（或在公众号 Tab 扩展源区附近）：AIHOT 专属刷新间隔（默认 30 分钟，可改）、分类规则表只读展示、热榜页启用开关

## 非功能需求

- N1: AIHOT 30 分钟间隔对目标站压力礼貌（单次 1 请求；失败重试不追加快请求）
- N2: 热榜页 500 条内容内滚动流畅（沿用游标分页/虚拟滚动）
- N3: 分类归类不调 AI（关键词+category 映射的确定性规则，零成本零延迟）
- N4: 英文原文抓取走服务端代理（关翻墙也能看），失败有兜底提示
- N5: 日期筛选在 5000 文章 + 1000 视频数据量下响应 <500ms（published_at 索引）

## 不做的事

- 不做主题聚类引擎（去重用关键词重叠启发式，不做向量聚类）
- 不做自动翻译（直接用 AIHOT 译文；英文原文抓原页不翻中文）
- 不抓 AIHOT 网页端的「AI 评分」（feed 无此字段；重要性由 F5 去重标注「另有 N 家报道」间接体现）
- 热榜不做 B站/抖音/官博混入（本期 AIHOT 独占数据源）
- 不改日报栏目规则引擎结构（F5 是其增强，不是重写）

## 验收标准

- AC1（F1）: AIHOT 源名显示「AIHOT 热榜」无乱码；新增中文名源不再乱码
- AC2（F2）: AIHOT 间隔设为 30 分钟后，日志显示约每 30 分钟抓取一次；设置页改值立即生效；恢复默认回到全局间隔
- AC3（F3）: 把生成时间设为过去、清空今日日报后打开 /daily/ → 自动生成并出现提示；9 点后打开即见今日内容
- AC4（F4）: 日历浮层选「近7天」后列表只含近7天内容，按钮显示范围；选阮一峰源后筛选仍生效；自定义 2003 年范围能筛出老文章；视频 Tab 同效；翻页正常
- AC5（F5）: 造两条不同源同事件内容生成日报 → 合并一张卡片带「另有 1 家信源报道」；某源同栏超 3 条时只留 3 条
- AC6（F6）: /hot/ 可访问 200；精选六类胶囊筛选正确（AIHOT 条目按其 category 归类）；全部动态搜索命中
- AC7（F7）: 卡片详情中文渲染完整；「查看英文原文」出英文全文（关翻墙也可）；失败时显示跳转兜底
- AC8（F8）: 设置页可见热榜设置区；改 AIHOT 间隔立即生效；关闭热榜开关后导航入口消失
